# Jest TDD Practice

A collection of exercises designed to practice **Test-Driven Development (TDD)** using **Jest**, as part of [The Odin Project](https://www.theodinproject.com/) JavaScript curriculum.

## About

The goal of this project is to practice writing tests before implementing functionality, using Jest to verify that each solution behaves as expected.

## Exercises

The project includes the following exercises:

- **Capitalize** – Capitalize the first character of a string.
- **Reverse String** – Reverse a given string.
- **Calculator** – Implement basic arithmetic operations.
- **Caesar Cipher** – Shift letters by a specified number while preserving case and punctuation.
- **Analyze Array** – Return an array's average, minimum, maximum, and length.

## Technologies

- JavaScript (ES Modules)
- Jest
- Babel

## Running Tests

Install dependencies:

```bash
npm install
```

Run the test suite:

```bash
npm test
```

Run the test watcher (automatically reruns tests when files change):

```bash
npm run watch
```

## Learning Objectives

- Practice Test-Driven Development.
- Write unit tests using Jest.
- Understand test assertions and expected results.
- Refactor code while maintaining passing tests.
